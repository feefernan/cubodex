# Cubodex

Cartas de pokémon, produtos selados e peças impressas em 3D — [@cubodex](https://instagram.com/cubodex)

```bash
npm install
npm run dev          # http://localhost:5173
npm run check        # tudo que o CI verifica
npm run test:e2e     # Playwright
```

Como contribuir (pessoas e agentes de IA): leia **[AGENTS.md](AGENTS.md)** — toda tarefa vira issue, todo código entra por PR com `Closes #N`, e o merge na `main` publica o site.
